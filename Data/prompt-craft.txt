════════════════════════════════════════
  KATEX MATH FORMATTING RULES  (critical — read carefully)
════════════════════════════════════════

The app renders math using KaTeX via renderMathInElement. Use these delimiters:

  Inline math  -->  $...$          e.g.  $x^2 + y^2 = r^2$
  Display math -->  $$...$$        e.g.  $$\int_0^\infty e^{-x}\,dx = 1$$

ALWAYS use KaTeX for:
  * Any variable, number in an equation, fraction, exponent, subscript
  * Chemical formulas           e.g.  $\text{H}_2\text{O}$
  * Units mixed with math       e.g.  $9.8\ \text{m/s}^2$
  * Vectors                     e.g.  $\vec{F} = m\vec{a}$
  * Greek letters               e.g.  $\alpha$, $\lambda$, $\Delta$
  * Integrals, limits, sums     e.g.  $\sum_{n=1}^{\infty}$
  * Matrices / determinants     e.g.  $\begin{vmatrix} a & b \\ c & d \end{vmatrix}$

COMMON CONVERSIONS — PDF notation -> KaTeX
  x^2                ->  $x^2$
  x_2                ->  $x_2$
  sqrt(x)            ->  $\sqrt{x}$
  cube root of x     ->  $\sqrt[3]{x}$
  a/b (fraction)     ->  $\dfrac{a}{b}$
  |x|                ->  $|x|$
  infinity           ->  $\infty$
  >= <= !=           ->  $\geq$  $\leq$  $\neq$
  x  /               ->  $\times$  $\div$
  arrow (->)         ->  $\rightarrow$
  plus-minus         ->  $\pm$
  degrees C          ->  $^\circ\text{C}$
  log base 10 of x   ->  $\log_{10} x$
  ln x               ->  $\ln x$
  sin / cos / tan    ->  $\sin\theta$  $\cos\theta$  $\tan\theta$
  sin squared x      ->  $\sin^2 x$
  n!                 ->  $n!$
  nCr                ->  $\binom{n}{r}$
  nPr                ->  $^nP_r$
  limit x->0         ->  $\lim_{x \to 0}$
  dy/dx              ->  $\dfrac{dy}{dx}$
  partial f/partial x->  $\dfrac{\partial f}{\partial x}$
  integral a to b    ->  $\int_a^b f(x)\,dx$
  sum i=1 to n       ->  $\sum_{i=1}^{n}$
  pi                 ->  $\pi$
  h-bar              ->  $\hbar$
  mu_0, epsilon_0    ->  $\mu_0$, $\varepsilon_0$

ESCAPING INSIDE JSON STRINGS  <-- THIS IS THE MOST COMMON MISTAKE
  Every backslash in a LaTeX command must be doubled inside a JSON string.

  LaTeX \frac   -->  JSON "\\frac"
  LaTeX \sqrt   -->  JSON "\\sqrt"
  LaTeX \times  -->  JSON "\\times"
  LaTeX \alpha  -->  JSON "\\alpha"
  LaTeX \text{} -->  JSON "\\text{}"

  Example:
    LaTeX:  $\frac{1}{2}mv^2$
    JSON:   "$\\frac{1}{2}mv^2$"

    LaTeX:  $\vec{F} = m\vec{a}$
    JSON:   "$\\vec{F} = m\\vec{a}$"

    LaTeX:  $\text{H}_2\text{SO}_4$
    JSON:   "$\\text{H}_2\\text{SO}_4$"

  Newlines inside string values are NOT allowed. Keep every field on one line.

════════════════════════════════════════
  SUBJECT-SPECIFIC TIPS
════════════════════════════════════════

PHYSICS
  * Always include units in math: $9.8\ \text{m/s}^2$, $3 \times 10^8\ \text{m/s}$
  * Vectors: $\vec{v}$, $\hat{i}$, $\hat{j}$, $\hat{k}$
  * Scientific notation: $6.022 \times 10^{23}$
  * Resistance R, current I, voltage V -- always italicise in $...$

CHEMISTRY
  * Chemical formulas in \text: $\text{H}_2\text{SO}_4$, $\text{CO}_2$
  * Reactions: $\text{A} + \text{B} \rightarrow \text{C}$
  * Molar mass: $M = 18\ \text{g/mol}$
  * State symbols: $(\text{aq})$, $(\text{s})$, $(\text{g})$

MATHEMATICS
  * Use \dfrac (not \frac) for fractions in questionText for better readability.
  * Piecewise functions: use \begin{cases}...\end{cases}
  * Matrices: \begin{pmatrix}...\end{pmatrix}
  * For display equations in question stem, prefer $$...$$ block syntax.

BIOLOGY
  * Scientific names in plain text (no math needed).
  * Where a formula appears (e.g. photosynthesis equation), use \text{} inside $...$

════════════════════════════════════════
  EDGE CASES & QUALITY RULES
════════════════════════════════════════

1. MULTI-PART QUESTIONS
   If a question has a shared passage/data block followed by sub-questions
   (i)(ii)(iii), treat each sub-question as a SEPARATE question object.
   Prepend the shared context to each questionText.

2. ASSERTION-REASON (A-R) TYPE
   questionText: "Assertion (A): ... Reason (R): ..."
   Use standard A-R options:
     A -> "Both A and R are true and R is the correct explanation of A"
     B -> "Both A and R are true but R is not the correct explanation of A"
     C -> "A is true but R is false"
     D -> "A is false but R is true"

3. MATCH THE COLUMN
   questionText: List Column I and Column II items clearly in the text.
   Options: Each option is a complete matching pattern e.g. "P-2, Q-3, R-1, S-4"

4. INTEGER / NUMERICAL ANSWER TYPE
   If the answer is a typed number (not MCQ), include four plausible options
   around the correct value and set correctAnswer to the index of the correct one.

5. STATEMENT TYPE (True/False statements)
   Options:
     A -> "Statement I is correct, Statement II is correct"
     B -> "Statement I is correct, Statement II is incorrect"
     C -> "Statement I is incorrect, Statement II is correct"
     D -> "Statement I is incorrect, Statement II is incorrect"

6. OPTION COUNT
   Always include ALL options given in the PDF (2, 3, 4, or 5).
   Never add or invent options not present in the PDF.

7. CORRECT ANSWER SOURCE
   Only set correctAnswer from an answer key visible in the PDF.
   If no answer key exists, set correctAnswer to 0 and write in explanation:
   "Answer key not provided in source PDF."

8. EXPLANATIONS
   If the PDF has a detailed solution, include it fully with KaTeX math.
   If only the correct option is given, leave explanation as "".
   Never fabricate or guess explanations.

9. QUESTION NUMBERING
   Do NOT include "Q1.", "1.", "(i)", "Question 5" etc. inside questionText.
   Strip all leading numbering -- the UI numbers questions automatically.

10. SPECIAL SYMBOLS
    Degree symbol    ->  $30^\circ$          (not a plain °)
    Dot product      ->  $\cdot$
    Perpendicular    ->  $\perp$
    Parallel         ->  $\parallel$
    Angle            ->  $\angle ABC$
    Triangle         ->  $\triangle ABC$
    Therefore        ->  $\therefore$
    Because          ->  $\because$
    Approximately    ->  $\approx$
    Proportional to  ->  $\propto$
    In set notation  ->  $\in$, $\subset$, $\cup$, $\cap$
